# DentAnki（歯科版 Anki + Quizlet）

ブラウザで動くPWAです。PDF問題抽出、日本語OCR、画像付き問題、誤答復習、間隔反復、タグ、科目別学習、国試100問モード、正答率・学習時間・苦手ランキング、端末間同期に対応します。

## 公開
フォルダ内を GitHub Pages / Netlify / Cloudflare Pages にアップロードしてください。`file://` 直開きではPDF.jsやService Workerが動かないため、HTTPSで公開します。

## iPhone・iPad同期
1. Supabaseで無料プロジェクトを作成
2. SQL Editorで `supabase/schema.sql` を実行
3. Authentication > Providers で Email を有効化
4. アプリの「設定」に Project URL と anon public key を入力
5. 同じメールアドレスでiPhone・iPadからログイン

データはRow Level Securityにより本人の行だけ読み書きできます。

## AI問題生成について
ブラウザへOpenAI等の秘密鍵を埋め込むのは危険なので、AI生成はサーバー側のSupabase Edge Function等を経由する前提です。この版では接続先URLの保存欄まで用意しています。PDF本文の送信・生成ロジックは利用するAIサービスに合わせて実装してください。

## スキャンPDF・OCR
- 「自動判定」では、埋め込み文字がほとんどないページだけ日本語＋英語OCRを実行します。
- 「全ページOCR」は文字情報が壊れているPDFにも使えますが、処理時間と端末負荷が増えます。
- OCRはTesseract.jsをブラウザ内で実行し、PDF画像を外部AIサーバーへ送信しません。
- 初回OCR時は日本語言語データをインターネットから読み込みます。

## 制限
- 低解像度、傾き、手書き、複雑な段組みではOCR精度が下がるため、抽出候補を手動修正してください。
- ページ画像は端末容量節約のため縮小JPEGです。

## 書き込み除去

PDF取込画面の「書き込み除去」から選択できます。

- **PDF注釈だけ除去**：Apple Pencil、PDF編集アプリのペン・蛍光ペン・コメントなど、注釈レイヤーとして保存された書き込みを描画せずに解析します。
- **色付き書き込みを除去**：注釈除去に加えて、ページ画像に焼き付いた赤・青など彩度の高い線を白くします。
- **強めに清書**：色付き線と薄い背景汚れを除去し、白黒を強調します。細い図や淡い組織像が消える可能性があります。
- **除去しない**：元の表示をそのまま解析します。

黒・灰色の手書きが画像に焼き付いている場合、印刷文字と画素上の違いがないため完全な自動除去はできません。図表や病理画像がある資料では「PDF注釈だけ除去」を推奨します。
